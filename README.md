# RopaShop (Ecommerce de Ropa)

Este proyecto tiene dos partes principales:
- Backend: maneja la lógica, la base de datos y la API.
- Frontend: muestra la tienda y permite interactuar con el sistema.

## Guías separadas

- Para el backend, mira [backend/README.md](backend/README.md)
- Para el frontend, mira [frontend/README.md](frontend/README.md)

## Resumen rápido

### Backend
- Usa Python + FastAPI.
- Administra usuarios, productos, carrito y órdenes.
- Expone una API REST.

### Frontend
- Usa React + Vite.
- Muestra la interfaz de la tienda.
- Se comunica con el backend mediante peticiones HTTP.

## Cómo arrancar el proyecto completo

1. Backend:
   - entra a [backend/README.md](backend/README.md)
   - crea el entorno virtual
   - instala dependencias
   - ejecuta el servidor

2. Frontend:
   - entra a [frontend/README.md](frontend/README.md)
   - instala dependencias
   - ejecuta la app
